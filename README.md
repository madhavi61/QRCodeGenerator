# QR Code Generator

This is a simple Python application that generates a QR code from a URL entered by the user.

## Requirements

- Python 3
- qrcode library
- Pillow

## Installation

Install the required packages using:

pip install -r requirements.txt

## How to Run

Run the Python program:

python qr_generator.py

Enter the URL you want to convert into a QR code.

Then, enter a name for the QR code image.

The program will generate and save the QR code as a PNG file.

## Example

Enter the URL you want to create a QR code for:
https://www.bioxsystems.com/

Enter a name for the QR code file:
biox_systems_qrcode

The QR code will be saved as:

biox_systems_qrcode.png
